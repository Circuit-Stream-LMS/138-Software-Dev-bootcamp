# CI/CD with GitHub Actions for a React Vite Project

## If you have not pushed the code to your github repository from the last class, then 

* Copy the contents of folder frontend-react into a brand new folder outside of the folder 138-March-Software-Development
* Once copied, open that folder in Vs Code in a terminal window and run 
``` git init ```
* On Github, create a new repository
* Run the following commands one by one to push to your remote repository
```
git add .
git commit -m "Commit message"
git add origin "link from your github repo"
git push -u origin main 
```
* Follow instructions in the file : [Deploy-react-on-render](../Lesson4-%20RenderForReact/deploy-react-vite-render.md)
